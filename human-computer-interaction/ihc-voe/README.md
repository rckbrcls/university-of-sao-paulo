# Voe

> **Status:** Archived
> This project is kept as academic coursework reference and may need setup verification before reuse.

Verifique se você tem baixado na sua máquina o Yarn e o Node (+ v.14)

Clone o repositório
```
git clone
```

Acesse o repositório
```
cd ihc-voe
```

Carregue os pacotes
```
yarn
```

Rode o projeto
```
yarn dev
```
