# Finite Automaton

> Status: archived academic coursework.

This project implements a deterministic finite automaton in Python and includes tests, manual/report material, a zip archive, and a packaged Windows executable.

## Scope

- Project type: standalone theory-of-computation assignment.
- Main stack: Python.
- Packaged artifact: Windows console executable under `executavel/`.
- Current status: archived study reference.

## Files

| Path | Purpose |
| --- | --- |
| `finite_automaton.py` | Main Python implementation with `FiniteAutomaton`, input parsing, and CLI-style interaction. |
| `test.py` | Unit-test scenarios for automaton acceptance behavior. |
| `manualT.txt` | Original manual for running the Windows executable. |
| `relatório.pdf` | Original assignment report. |
| `trabalho-itc.zip` | Archived package. |
| `executavel/finite_automaton.exe` | Packaged Windows executable. |

## Behavior

The Python script reads automaton configuration from standard input:

- number of states;
- alphabet symbols;
- acceptance states;
- transition count;
- transitions;
- strings to test.

It then prints `aceita` or `rejeita` for each tested string.

## Running From Source

```sh
cd introduction-to-the-theory-of-computation/finite-automaton
python3 finite_automaton.py
```

## Tests

`test.py` contains `unittest` test cases for accepted and rejected strings. In the current codebase, the test file does not include the required imports for `unittest` or `FiniteAutomaton`, so it documents intended scenarios but may need small setup fixes before it can run directly.

## Packaged Executable

`executavel/finite_automaton.exe` is a Windows PE executable. `manualT.txt` documents the original Windows workflow:

```text
Open the executavel folder and run finite_automaton.exe.
```
