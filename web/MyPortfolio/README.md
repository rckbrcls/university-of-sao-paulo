# MyPortfolio

> Status: archived static web template coursework/reference.

This folder contains a static portfolio website based on the BootstrapMade MyPortfolio template. It includes HTML pages, CSS, JavaScript, images, vendor libraries, and a placeholder PHP contact form.

## Scope

- Project type: static website/template copy.
- Main stack: HTML, CSS, JavaScript, Bootstrap, vendor frontend libraries, and optional PHP contact form handling.
- Build system: none identified.
- Current status: archived study reference.

## Contact Form

`forms/contact.php` is a placeholder template integration for BootstrapMade's PHP Email Form library. The current file uses `contact@example.com` as the receiving address and comments out SMTP settings. It should not be treated as a configured production email workflow.

## Usage

Open `index.html` in a browser for static inspection. A local PHP-capable server is only needed if testing the PHP contact form behavior.
